# DoppelBot Analysis

This repository contains the code and data for the DoppelBot analysis.

## Instructions
1. To run prompting expirment run `./bin/generation/prompt_for_humanity_0.sh`
2. Then for evaluation run `./bin/eval/eval_humanity.sh`
3. The app that we used for annotation can be viewed at `./src/streamlit`
4. Finally expirements can be found in the `./src/analysis` and `./src/statistical_tests` folders
