# DoppelBot Collection

This repository contains the code, analysis pipelines, and supporting software for the DoppelBot project.

## Repository Structure

### TerminalGame/
The original terminal-based DoppelBot application used for the experiments reported in the paper.

### DoppelAnalysis/
Analysis, evaluation, annotation, and statistical testing code used to generate the results presented in the paper.

### WebGame/
A web-based implementation of DoppelBot developed to support future research and data collection.

## Data Availability
The dataset contains interactions from minor participants and is not publicly hosted.

De-identified game transcripts, voting records, and interview annotations may be shared with qualified researchers who obtain appropriate IRB approval (or documentation that IRB review is not required).

## Reproducing the Paper
The repository is organized into independent components.

1. `TerminalGame/`
   - Original experimental platform.

2. `DoppelAnalysis/`
   - Evaluation pipelines.
   - Statistical analyses.
   - Annotation tools.
   - Figure generation scripts.

3. `WebGame/`
   - Web-based implementation of the game.

Please consult the README file within each subdirectory for setup instructions and usage details.
