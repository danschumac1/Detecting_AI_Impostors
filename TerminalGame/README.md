# Terminal Game
This repository contains the code to run the DoppelBot terminal application.

##  Instructions
1. conda create -n doppelEnv python=3.10.12
2. conda activate doppelEnv
3. pip install -r ./resources/requirements.txt
4. creat `.env` in `./resources` 
5. set OPENAI_API_KEY=sk-proj- ...
6. To play the game:
    - Each player runs python `./src/main.py` 
    - enters the same lobby number and number of players when prompted to.
